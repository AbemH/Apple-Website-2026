# Apple Website 2026

This project is a recreation of Apple's website design at the time I worked on it. It builds on my earlier Apple Website 2020 project, using a more recent version of Apple's homepage as the reference.

I used HTML and CSS to recreate the updated layout, navigation, promotional sections, and responsive design.

## Technologies Used

- HTML
- CSS
- Font Awesome
- Google Fonts

## Features

- Updated Apple-style navigation
- Product and promotional sections
- Responsive layout for different screen sizes
- Product images and icons

## How to Run

Open `2026Applewebsite/index.html` in your browser.
